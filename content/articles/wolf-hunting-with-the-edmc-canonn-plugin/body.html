This video demonstrates how to use the EDMC-Canonn plugin to locate Wolf-Rayet stars in Elite Dangerous, which helps Commanders earn the EDSM Wolf Hunter badge.

Key steps to wolf hunting

  1. Identify high-mass systems. Wolf-Rayet stars are typically found in high-mass areas. Search for system names that contain the string "AA-A h".
  2. Use the plugin for search. Type a sector name and the plugin populates a dropdown list of systems. Click a system to reveal its star class in an information box.
  3. Verify with the database. The plugin automatically checks systems against the Spansh database:
    • Amber: the system has been logged in the database, but it may not have been visited yet.
    • Red: the system is missing from the database, which usually means it is also missing from EDSM.
