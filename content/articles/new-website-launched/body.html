You may have been wondering what happened to our old website at canonn.science. Unfortunately it was brought down by a recent security vulnerability at our hosting provider, and it was at this point that we discovered our website administrator, Captain Rebuy, was lost in space.

Up until now we have been reluctant to make any formal announcement, because we had hoped that we would be able to locate him healthy and well, but all our attempts to make contact have so far failed.

Subsequently we have made the decision to rebuild the website using different technology, and thanks to the efforts of LilacLight and LCU No Fool Like One we have recovered most, if not all, of the old content and represented it here.

There is much work still to do. We need to find images for missing articles, recover lost articles, and reformat and embed data. But this is where you can help. At the bottom of each page are buttons you can use to report issues with data, or even submit new articles for publication. You will need an account on GitHub to submit issues.

Likewise, if there are new features you would like to see, you can submit a feature request, or even, if you are so inclined, make a fork of the website, make the changes yourself, and submit us a pull request for approval.

The site is being actively developed, so please expect frequent changes and updates. Once the dust has settled, we hope to regain access to our canonn.science domain and will move the site back to its old address, so that any links from external sites will still work. In the meantime, if you want to update any links from your Discord or other documentation, you should be able to replace canonn.science with science.canonn.tech.

We look forward to your feedback.
